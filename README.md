Personal Blogging Platform API
A RESTful API for a personal blogging platform built with Node.js, Express, and SQLite. This API provides full CRUD operations for blog posts with search functionality.

Features
✅ Create, Read, Update, Delete blog posts

✅ Search functionality with filter by title, content, or author

✅ RESTful design with proper HTTP methods and status codes

✅ SQLite database with automatic setup and sample data

✅ Error handling with meaningful error messages

✅ CORS enabled for cross-origin requests

✅ Health check endpoint for monitoring

Tech Stack
Node.js - Runtime environment

Express.js - Web framework

SQLite3 - Database

CORS - Cross-origin resource sharing

Body-parser - Request body parsing
